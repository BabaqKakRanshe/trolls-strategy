# Troll Strategy

Минимальная визуальная сборка на Phaser 4 без спрайтов и текстур. На белом игровом поле находятся красный рынок и синий склад, слева показаны золото и число существ, справа расположен простой магазин.

Стартовый запас — 1000 золота. В магазине можно купить геометрического гоблина за 40 золота и один раз открыть шахту за 200 золота. Остальные игровые механики сохранены в headless-слоях проекта.

## Запуск

Требуется Node.js `20.19+`, `22.13+` или `24+`.

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
```

## Структура

- `src/game/scenes/MinimalScene.ts` — геометрическая игровая сцена;
- `src/ui` — счётчики и доступные кнопки магазина;
- `src/domain` — чистые игровые правила;
- `src/application` — `GameSession`, команды и immutable snapshots;
- `src/content` — параметры игровых сущностей и миссии;
- `src/persistence` — save codec и адаптеры автосохранения;
- `assets` — сохранённые исходные пользовательские ассеты, не подключённые к runtime.
- `docs` — проектные решения, планы реализации и архив архитектурных аудитов.

Каталоги `node_modules` и `dist` создаются локально командами npm и не хранятся в Git.

## Проверки

```bash
npm test
npm run lint
npm run build
```

Тест минимальной сцены запрещает загрузку спрайтов, изображений, текстур и аудио.
