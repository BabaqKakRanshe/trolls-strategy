# Troll Strategy — экономика поселения

Актуальный [ГДД игры](docs/GDD.md) описывает полные производственные цепочки и будущие бои; ниже — состояние Unity-версии.

## Unity: 3D-поселение

Арт-направление — стиль KayKit: крупная огранка, плоское затенение, синяя кровля,
холодный камень, лаймовая трава. Набор `assets/Strategy_Kit` переведён в этот стиль;
в Unity импортированы десять новых моделей производственных зданий, их prefab variants
с коллайдерами и расширенная палитра. В каталоге **Здания** кнопки «Посмотреть» открывают
вращающееся 3D-превью каждой новой модели. Сохранённая сцена по-прежнему использует четыре здания прежней версии;
для полного обновления окружения нужны повторный импорт остальных моделей и
`TrollStrategy → Dev → Refresh Diorama`. Границы и проверки — в [арт-направлении](docs/diorama-art-direction.md).

Проект в [Unity](unity/TrollStategy) открывается в Unity `6000.6.0f1`. Запустите сцену `Assets/Game/Scenes/MainColonyScene.unity`. Здания, деревья и декор используют импортированный набор Vitaria из `Assets/Vitaria`; игровая поверхность и дорожки сохраняют геометрию для сетки 14×14. Гоблины и тролли остаются анимированными 2D-спрайтами, обращёнными к камере. У зданий есть видимый южный вход, к которому подходят рабочие. HUD оформлен в цветах набора: верхняя полоса ресурсов, выдвижной каталог и подсказки размещения. Экономика и размеры клеток не менялись. Пересборка визуальной сцены: **TrollStrategy → Dev → Refresh Diorama**; обновление интерфейса: **TrollStrategy → Refresh HUD Only**.

`TrollStrategy → Dev → Setup Game Scene` создаёт сцену сразу в этом виде.

## Проект и материалы

- Основной проект: [`unity/TrollStategy`](unity/TrollStategy).
- Сцена для запуска: `Assets/Game/Scenes/MainColonyScene.unity`.
- Исходные 3D-модели и генератор: [`assets/Strategy_Kit`](assets/Strategy_Kit).
- Правила и целевые механики: [`docs/GDD.md`](docs/GDD.md).
- Проверки игрового кода находятся в `Assets/Game/Tests/EditMode` внутри Unity-проекта.

Исходный арт и сведения о лицензиях хранятся в `assets`; используемые игровые спрайты импортированы в Unity-проект.
