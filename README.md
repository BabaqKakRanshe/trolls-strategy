# Troll Strategy — экономика поселения

Играбельный 2D-прототип на Phaser 4. Текущий срез намеренно ограничен одной производственной цепочкой:

```text
шахта → склад → рынок → золото
```

Игрок строит несколько шахт, нанимает гоблинов и троллей, назначает до пяти рабочих в шахту и создаёт постоянные маршруты перевозки. Носильщики физически идут между зданиями, загружают руду, несут ограниченный объём и разгружаются. Рынок продаёт доставленную руду по 3 золота.

## Запуск

Требуется Node.js `20.19+`, `22.13+` или `24+` и Python 3.9+.

```bash
npm install
npm run dev
```

Откройте `http://127.0.0.1:5173`.

## Управление

- кнопка «Построить» включает сетку и режим размещения шахты;
- ЛКМ по свободной клетке ставит шахту, ПКМ отменяет режим;
- в разделе найма выберите количество от 1 до 20, нажмите «Нанять», затем один раз кликните по нужной клетке поля — вся группа появится в ней;
- ЛКМ по юниту выбирает его, `Ctrl+ЛКМ` добавляет или убирает из группы;
- протягивание рамки по земле выделяет несколько юнитов;
- ПКМ по выбранному существу открывает веер гексов с приказами;
- `G` скрывает или снова показывает сетку;
- `F1` открывает окно отладки, где можно показать реальные области коллизий;
- «Работа» → шахта назначает выбранных работников;
- «Перенос» → источник → получатель создаёт постоянный маршрут;
- «Свободны» снимает выбранных юнитов с работы или маршрута;
- квадратное поле имеет размер 14×14, в одной клетке толпой помещается до 20 существ;
- нативные кнопки приказов остаются клавиатурной альтернативой и появляются при получении фокуса.

## Текущие значения

| Объект | Цена | Сила | Скорость | Груз |
|---|---:|---:|---:|---:|
| Гоблин | 40 | 3 | 5 | 10 |
| Тролль | 170 | 9 | 2 | 30 |

- шахта стоит 200 золота, занимает 3×3 клетки, вмещает 5 рабочих и 100 руды;
- склад вмещает 500 руды;
- добыча шахты: `0.1 × сумма силы рабочих` руды в секунду;
- скорость носильщика: `120 + скорость × 12` игровых пикселей в секунду;
- загрузка и разгрузка занимают по 500 мс;
- экономика рассчитывается фиксированными шагами по 250 мс.

## Архитектура

- `src/content/catalog.ts` — единственный источник цен и числовых параметров;
- `src/domain/colony.ts` — чистые команды, размещение и fixed-step симуляция;
- `src/application/GameSession.ts` — единственный владелец изменяемого состояния;
- `src/application/MapInteractionController.ts` — только выделение и режимы ввода;
- `src/game/ColonyScene.ts` — отрисовка Phaser из immutable snapshots;
- `src/ui/AppUi.ts` — HUD, магазин и доступные DOM-команды;
- `src/main.ts` — композиция приложения.

Автобой, экипировка, сохранения, крафт, фермы и нападения в этот срез не входят.

## Проверки

```bash
npm run lint
npm test
npm run build
npm run e2e
```

Unit-набор содержит только критические проверки экономики. Один Playwright-сценарий проходит полный видимый путь от строительства шахты до продажи руды.

## Ассеты и лицензии
