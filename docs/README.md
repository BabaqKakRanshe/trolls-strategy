# Документация

- `plans/design/` — принятые проектные решения и дизайн вертикальных срезов.
- `plans/implementation/` — исторические пошаговые планы реализации.
- `audits/` — архив архитектурных аудитов с указанием проекта в имени файла.

Документы описывают решения и историю проекта. Актуальные команды запуска и текущая
структура находятся в корневом `README.md`.
