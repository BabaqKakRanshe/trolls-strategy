# Палитра 3D-поселения

Обновление 24.09.2026: для выбранной тёплой диорамы три здания получили новую
палитру материалов из `DioramaModelBuilder.cs`, окружение — из `PrimitiveEnvironment.cs`.
Ниже сохранена запись предыдущей перекраски; полоса образцов больше не описывает
все текущие материалы. Актуальное состояние образца: [направление диорамы](diorama-art-direction.md).

Источник: [полоса образцов](colony-palette.png), 46 цветов по 32 пикселя. Значения ключевых образцов зафиксированы в `ColonyPalette.cs`; игровые правила и трансформации сцены от цвета не зависят.

| Область | Где применяется | Состояние | Проверка |
| --- | --- | --- | --- |
| Земля, дороги, хвойный лес, камни | `PrimitiveEnvironment`, материалы в `Assets/Game/Art/Materials` | Перекрашено | Цвета материалов сверены с образцами; положение объектов не менялось |
| Шахта, склад, рынок, казармы | `PrimitiveBuilding`, материалы в `Assets/Game/Art/Materials` | Перекрашено | Исходные значения и сохранённые материалы обновлены |
| Сетка, маршруты, выделение, размещение | Компоненты `Runtime/Presentation` | Перекрашено | C# сборка прошла |
| HUD, карточки, кнопки, динамические списки | Сцена и `Runtime/UI` | Перекрашено | Изменены только поля цвета в сцене; C# сборка прошла |
| Спрайты персонажей | Исходные текстуры персонажей | Сохранены | Изменён цвет выделения; текстуры не трогали |

Текущая сцена пользователя не перестраивалась: строки позиций, поворотов и масштабов остались прежними. Unity EditMode тесты ожидают доступности редактора; на момент изменения проект был открыт в другом экземпляре Unity.
