# Переделка HUD на UI Toolkit

Дата: 27.09.2026. Основание: аудит UI от 26.09 (весь HUD собирался кодом в пяти местах, мёртвые view, неверные цены, клавиатурные действия без кнопок).

## Решение

Экранный UI колонии и боя переходит с uGUI на UI Toolkit (UXML + USS). Подписи над объектами в мире остаются на TMP в `Runtime/Presentation`.

- Вёрстка и стили — `Assets/Game/UI/` (`Uxml/`, `Styles/`, `Fonts/`, `Settings/`). Один `Theme.uss` задаёт цвета, шрифт, кнопки и панели; экраны не хранят цветов в C#.
- Шрифт — Rubik 1.x (OFL, кириллица), лицензия лежит рядом со шрифтом.
- Код — `Runtime/UI/Common` (кнопки, анимации, счётчики), `Runtime/UI/Colony` (HUD колонии), `Runtime/UI/Battle` (HUD боя, второй этап).
- `ColonyHud` (MonoBehaviour с `UIDocument`) только связывает документ, сессию и ввод. Экранные части — обычные классы поверх `VisualElement`, их проверяют EditMode-тесты без сцены.
- UI читает снимки и зовёт `InteractionController`; цены, возвраты и таймеры берутся из каталога и сессии.
- Клики по карте блокирует `UIInputUtils`: он спрашивает панели UI Toolkit через `Pick`, контейнеры разметки имеют `picking-mode: Ignore`.
- Отзывчивость (звук, пружина, отказ) переносится из `ButtonFeel`/`CounterFeel` в `UiFeel`/`UiMotion`/`CounterLabel`.

## Состав HUD колонии

| Зона | Содержимое |
| --- | --- |
| Верх | название, золото/руда/население/продано, кнопки «Свободный (1)», «Сетка (G)», «В бой», «Каталог» |
| Справа | каталог: существа (число найма, карточки из каталога) и все строящиеся здания одним списком, осмотр модели |
| Слева | карточка выбранного здания или юнита |
| Низ по центру | панель контекста: команды выбранным (W/H/R, бараки, продажа), подсказка режима, цели, «Авто», «Отмена» |
| Низ слева | строка статуса с отказом |
| У курсора | веер команд по ПКМ |
| F1 (dev) | чит-меню |

## Этапы

1. HUD колонии, удаление старых view и uGUI-канваса колонии, сцена, тесты, сборка.
2. HUD боя из `BattleSceneController` в `Runtime/UI/Battle`, удаление `ButtonFeel`/uGUI-пути в `UIInputUtils`.

Готово, когда проходят компиляция, EditMode-тесты, проверка в Play Mode и сборка Windows player.
