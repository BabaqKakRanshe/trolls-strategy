# Data Model: Указатель обучения

**Feature**: `006-tutorial-guidance` | **Date**: 2026-10-06

Состояние кампании (`GameState`), команды и сохранения не меняются. Ниже — экранные модели. Их заново строят при каждом обновлении HUD, и они ничем в колонии не владеют.

## GuideStep (UI, `Runtime/UI/Common/GuideStep.cs`)

Одно следующее нажатие обучения.

| Поле | Тип | Смысл |
|---|---|---|
| `Target` | `GuideTarget` | что нажать |
| `Title` | string | действие, жирно в карточке: «Найми первого работника», «1. Откуда: склад» |
| `Text` | string | одна строка «как» или «зачем» |
| `Number`, `Count` | int | «Шаг N из M»; при `Count` ≤ 1 строки нет |
| `Veil` | bool | класть ли вуаль; нет — у окон со своей вуалью (груз, арена) |
| `Key` | string | ключ шага: задание, цель, номер, цель; со сменой ключа вуаль возвращается и камера снова может подъехать |

`GuideStep.None` — указателя нет: после обучения, подсказки выключены, у цели нет одного нажатия, открыты награда, меню, книга, вводное окно.

## GuideTarget

| Вид (`GuideTargetKind`) | Чем задан | Где на экране |
|---|---|---|
| `Element` | `VisualElement` HUD | `worldBound` в панели |
| `Building` | id здания | `ColonyHudContext.BuildingToScreen(id)` |
| `Unit` | id существа | `ColonyHudContext.UnitToScreen(id)`, каждый кадр (существо идёт) |
| `Cell` | клетка | квадрат клетки через `MapToScreen` |
| `Footprint` | клетка и размер здания | четыре угла места через `MapToScreen` |
| `BattleCell` | клетка поля боя | `IBattleScreen.LocateCells` |

Цель на карте вне экрана: окно и вуали нет, рука у края смотрит на цель, рядом круглая кнопка «к цели» (`InteractionController.Focus`).

## Шаги колонии (`ColonyGuide`)

Шаг строится из `QuestSnapshot.NextGoal`. Подготовка — «вернись к каталогу», «открой каталог», «вкладка» — берёт номер того шага, к которому ведёт.

### Нанять (`OwnUnits`; работа или перенос без свободного существа)

| № | Когда | Цель | Карточка |
|---|---|---|---|
| 1 из 1 | первое существо колонии (короткий путь) | жетон вида | «Найми первого работника» — «Нажми на жетон «Гоблин»: он сам встанет у склада.» |
| 1 из 2 | иначе | жетон вида | «Найми работника» — «Нажми на жетон «Гоблин».» |
| 2 из 2 | режим `PlacingUnits` этого вида | клетка `TutorialPlaces.HireCell` | «Сюда» — «Кликни по клетке у склада: отсюда ближе всего носить.» |

### Построить (`OwnBuildings`)

| № | Когда | Цель | Карточка |
|---|---|---|---|
| 1 из 2 | — | жетон здания (вкладка «Здания») | «Построй здание» — «Нажми на жетон «Шахта».» |
| 2 из 2 | режим `PlacingBuilding` | место `TutorialPlaces.BuildingCell` | «Сюда» — «Кликни по месту у склада или нажми «Поставить сам».» |

### Работать (`WorkAt`)

| № | Когда | Цель | Карточка |
|---|---|---|---|
| 1 из 3 | никто подходящий не выделен | свободное существо | «Выбери работника» — «Кликни по свободному существу на острове.» |
| 2 из 3 | выделен свободный подходящий | «Работа» | «Работа» — «Нажми «Работа» (E), потом на здание.» |
| 3 из 3 | режим `ChoosingWorkTarget` | здание цели со свободным местом | «Куда на работу» — «Кликни по зданию «Шахта».» |

### Носить на склад (короткий путь 6C)

Цель `HaulRoute` с `Destination == Warehouse`, игрок не в режиме переноса.

| № | Когда | Цель | Карточка |
|---|---|---|---|
| 1 из 2 | карточка этого здания закрыта | здание-источник | «Здание «Шахта»» — «Нажми на него: в карточке есть «Вывозить на склад».» |
| 2 из 2 | карточка открыта, кнопка доступна | «Вывозить на склад» | «Вывозить на склад» — «Свободный гоблин начнёт носить отсюда на склад.» |

### Носить двумя зданиями (6A)

Цель `HaulRoute`, остальные случаи.

| № | Когда | Цель | Карточка |
|---|---|---|---|
| 1 из 5 | никто подходящий не выделен | свободное существо | «Выбери носильщика» — «Кликни по свободному существу на острове.» |
| 2 из 5 | выделен свободный подходящий | «Перенос» | «Перенос» — «Нажми «Перенос» (H): дальше два здания, откуда и куда.» |
| 3 из 5 | `ChoosingHaulSource` | здание-источник | «1. Откуда: склад» — «Кликни по зданию, откуда носить.» |
| 4 из 5 | `ChoosingHaulCargo` | «Куда носить» в окне (без вуали) | «Что носить» — «Можно оставить «Всё» и нажать «Куда носить».» |
| 5 из 5 | `ChoosingHaulDestination` | здание цели | «2. Куда: рынок» — «Кликни по зданию: туда понесут груз.» |

### Бой (`WinBattles`, `ReachArenaLevel`, `WearGearInBattle`)

Шаги колонии и боя (`BattleGuide`) идут одним счётом.

| № | Когда | Цель | Карточка |
|---|---|---|---|
| 1 | окно арены закрыто | «Арена» | «Арена» — «Нажми «Арена»: там уровни боёв.» |
| 2 | окно арены открыто (без вуали) | «В бой» | «В бой» — «Уровень выбран: нажми «В бой».» |
| 3 | на поле никого | «Авторасстановка» | «Авторасстановка» — «Бойцы сами встанут на синие клетки.» |
| 4 (броня) | надето меньше n, никто не выбран | боец на поле | «Выбери бойца» — «Кликни по бойцу на поле: внизу появится его снаряжение.» |
| 5 (броня) | выбран боец, есть свободный предмет в его пустую ячейку | жетон предмета | «Снаряжение» — «Нажми на «Ржавый меч»: боец наденет его.» |
| последний | — | «Начать бой» | «Начать бой» — «Бой идёт сам.» |

Всего: 4 шага у «Первого боя», 6 у «В броне на арену».

Если игрок в чужом режиме (строит, когда нужна работа), шаг — «Отмена» в нижней панели: «Сначала отмени» — «Нажми «Отмена» (Esc).»

## TutorialPlaces (Application, `Runtime/Application/TutorialPlaces.cs`)

| Метод | Возвращает |
|---|---|
| `HireCell(session, kind, amount)` | клетка у двери ближайшего склада, где `CanBuyUnits` — Ok, или null |
| `BuildingCell(session, kind)` | левая нижняя клетка места у двери склада, где `CanPlaceBuilding` — Ok, или null |
| `Warehouse(snapshot)` | первый склад колонии или null |

Поиск идёт кольцами от точки перед дверью (`ColonyNavigation.DoorwayAt(...).Approach`) по сетке, до её края.

## Настройка

`GameSettings.TutorialHints` (bool, PlayerPrefs `settings.tutorialHints`, по умолчанию true) — показывать ли указатель, вуаль и карту свободных клеток. Хранится с настройками игры, не с колонией.

## Что не меняется

- `GameState`, команды, `GameSnapshot`. Новые запросы приложения только читают.
- Боты: `TrollStrategy.Bots` не пользуется `InteractionController` и HUD.
- Сохранений в игре нет.
