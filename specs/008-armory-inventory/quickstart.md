# Quickstart: как проверить склад экипировки и склад

Пути — от корня репозитория. Unity-проект — `unity/TrollStategy`.

## Предусловия

- **Чужая работа закоммичена.** Рецепты картинками и «Подробнее» (другая сессия) и удаление «Нанять» (родительская сессия) — в рабочей ветке, `InspectPanel.cs`, `Inspect.uxml`, `WikiPanel.cs`, `GameSession.cs` и `NewPanelsTests.cs` не грязные от чужих правок.
- **Редактор.** Unity 6000.6. Если проект открыт у владельца или других агентов — проверка на копии `C:\tmp\<имя>` (память: `unity-private-copy-verification`, `unity-batchmode-verification`). Для быстрой проверки компиляции без редактора — офлайн-компиляция (память: `unity-offline-compile`).
- **Локализация собрана:**
  - `python tools/localization/extract.py`;
  - перевод новых ключей во все 15 файлов `tools/localization/translations`, `python tools/localization/validate.py <code>` по каждому;
  - `python tools/localization/build.py`;
  - меню `TrollStrategy/Dev/Setup Localization Fonts`.

## 1. EditMode

Фильтры: `ArmoryCard`, `NewPanels`, `ColonyHud`, `Progression`, затем весь набор.

| Сценарий | Ожидание | Требование |
|---|---|---|
| Стартовая колония со складом экипировки | две ячейки: ржавый меч 1, латаная броня 1; «В запасе: 2»; сетки «На бойцах» нет | US1-1, US3-5 |
| `DebugGrantGear(3)` | 30 ячеек; ржавый меч и латаная броня 4, остальные 3; 15 с `is-enchanted`; порядок оружие → броня → шлемы, простые раньше зачарованных | FR-001–003, SC-002 |
| Снимок, где двое бойцов носят железные мечи | «На бойцах: 2», ячейка железного меча 2, подсказка «Носят: A, B.»; в запасе на 2 меньше | US3-1 |
| Тот же снимок без одного владельца (продан) / без предмета (пал) | меч вернулся в запас / пропал из обеих сеток | US3-2, US3-3 |
| Любой из снимков выше | `InStock + OnFighters == snapshot.Equipment.Count`; `DescribeGoal(OwnEquipment)` = «Снаряжение колонии, предметов» | FR-006 |
| Всё надето | «Запас пуст: всё снаряжение на бойцах.» | FR-007 |
| Снаряжения нет | «Запас пуст: проложите сюда перенос…», сеток нет | US1-5 |
| 1500 предметов одного вида | в ячейке «999+», в подсказке 1500 | Edge |
| Карточка склада | подпись — строки `ExplainStorage`, со словами о складе экипировки; подсказка ячейки — название товара и «В ячейке: N из 50» | US2-1, FR-013 |
| Подсказка жетона склада экипировки в каталоге | те же строки, что подпись карточки | US2-3, FR-011 |
| Книга: поиск «склад» | склад и склад экипировки | US4-1 |
| Книга: склад / рынок | «Стоит на острове с начала игры.», цены в списке «—»; у склада «Хранит» — 23 чипа, нажатие открывает страницу товара | US4-2 |
| Книга: склад экипировки | абзацы `ExplainStorage`, «Хранит»: 30 чипов, сначала простые, у 15 зачарованных кайма | US4-3 |
| Карточка склада → «Подробнее» | книга на складе | US4-4 |

## 2. Снимки интерфейса

```text
Unity.exe -batchmode -projectPath unity/TrollStategy -executeMethod TrollStrategy.Editor.Tools.HudSnapshots.RunBatch -hudSnapshots <dir> -hudLanguages ru,en,de
```

Плюс тот же прогон с `-hudSize 1280x720`.

| Снимок | Что смотреть |
|---|---|
| `<lang>-warehouse` | сетка склада как раньше, подпись в 2 строки, ничего не обрезано |
| `<lang>-armory` | стартовое снаряжение, подпись в 3 строки |
| `<lang>-armory-full` | `DebugGrantGear(3)` и несколько бойцов в снаряжении. Обе сетки по 4 ряда, прокрутка внутри карточки, строка улучшения видна, на 1280×720 карточка не выходит за экран (SC-003) |
| `<lang>-wiki-warehouse`, `<lang>-wiki-armory` | абзацы и чипы «Хранит» читаются, длинные названия на других языках переносятся, а не обрезаются |

## 3. Сдача

- Весь набор EditMode зелёный, компиляция без предупреждений по новым файлам.
- `TrollStrategy/Build Windows Player` → `Builds/Windows/build-result.txt` — успех.
- В сборке или Play Mode на копии:
  - построить склад экипировки;
  - провезти мечи из кузницы и смотреть, как растёт ячейка;
  - выдать меч бойцу в расстановке, провести бой, увидеть его в «На бойцах»;
  - продать бойца и увидеть меч в запасе.
- Боты не затронуты: прогон кампании не обязателен, если не делалась история 5. После переименования — `tools/bots/run-bots.ps1 -NoOpen`, все профили проходят кампанию.
